# methodsort — Разработка под ключ

Портфолио-витрина для продажи Telegram-ботов, сайтов, автоматизации, парсеров и интеграций API.

## Живой сайт

- GitHub Pages: https://emoread23.github.io/methodsort-portfolio/

## Что внутри

- главный экран с позиционированием;
- услуги: боты, сайты, автоматизация;
- стек: Python, Node.js, TypeScript, React, n8n;
- процесс работы;
- блок статистики;
- 6 интерактивных кейсов с публичными ссылками;
- контакт на Telegram: https://t.me/methodsort

## Как отправлять клиенту

Можно писать так:

> Делаю Telegram-ботов, сайты и автоматизацию под ключ. Вот мое портфолио с примерами работ: https://emoread23.github.io/methodsort-portfolio/

## Локальный просмотр

Откройте `index.html` в браузере.
